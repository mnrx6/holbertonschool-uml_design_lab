Problem Analysis - Music Streaming Platform

Main Entities:
- User
- Artist
- Album
- Song
- Playlist
- Library

Key Relationships:
- An Artist can create multiple Albums.
- An Album belongs to one Artist.
- An Album contains multiple Songs.
- A Song belongs to one Album.
- A User can create and manage multiple Playlists.
- A Playlist can contain multiple Songs.
- A Song can be added to multiple Playlists.
- A User can follow multiple Artists.
- A User has one personal Library.
- A Library can contain multiple Songs and Albums.

Main Use Cases:
- Browse songs and albums.
- Create a playlist.
- Add a song to a playlist.
- Remove a song from a playlist.
- Save a song to the library.
- Save an album to the library.
- Follow an artist.
- View user playlists.
- View saved songs and albums.
